# Walk-mode music

Only freely licensed tracks belong here. `tracks.json` lists them (file, title, author, license, url);
files that are missing are skipped, and with none present walk mode is silent.

- Mirrorshade (cinameng / James Gargette), CC0 — https://opengameart.org/content/mirrorshade
  Download `mirrorshade_1.mp3` from that page into this folder.

Do not add commercial recordings.
